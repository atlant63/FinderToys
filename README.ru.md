**FinderToys** расширяет стандартный Finder в macOS интуитивным управлением с клавиатуры, умным созданием файлов из буфера обмена и удобным контекстным меню по правому клику мыши. Приложение полностью нативное, написано на Objective-C и AppKit, потребляет ~0% процессора, не использует Electron и гармонично вписывается в экосистему macOS.

---

## ⚡ Быстрая установка

### Способ 1: Установка одной командой в Терминале (Рекомендуется)
Откройте «Терминал» и вставьте команду:
```bash
curl -fsSL https://raw.githubusercontent.com/Danikk13/FinderToys/main/install.sh | bash
```

### Способ 2: Скачать DMG-образ
1. Скачайте **[`FinderToys.dmg`](https://github.com/Danikk13/FinderToys/releases/latest/download/FinderToys.dmg)**.
2. Откройте загруженный `.dmg` и перетащите иконку **FinderToys** в папку **«Программы»**.
3. Запустите **FinderToys** из Программ.

## ✨ Возможности

### ⌨️ Интуитивные горячие клавиши
| Действие | Сочетание клавиш | Описание |
| :--- | :--- | :--- |
| **Открыть файл/папку** | <kbd>Enter</kbd> (Return) | Мгновенно открывает выбранный элемент вместо его переименования. |
| **Переименовать файл/папку** | <kbd>F2</kbd>, <kbd>⌥ Option + F2</kbd>, <kbd>⌘ Cmd + R</kbd> | Запускает стандартное переименование без задержек. |
| **Альтернативное переименование** | <kbd>⇧ Shift + Enter</kbd>, <kbd>⌥ Option + Enter</kbd> | Дополнительные удобные комбинации для переименования. |

> [!NOTE]
> **Защита ввода:** При редактировании текста (переименование файла, поиск в Finder или переход к папке) клавиши <kbd>Enter</kbd> и <kbd>⌘V</kbd> работают в обычном текстовом режиме и не перехватываются.

---

### 📋 Умная вставка из буфера (<kbd>⌘ Cmd + V</kbd>)
Нажмите <kbd>⌘V</kbd> в любой открытой папке Finder или на Рабочем столе для мгновенного сохранения содержимого буфера обмена в файл:

* **Картинки:** Скопировали скриншот, мем или изображение в браузере? Нажмите <kbd>⌘V</kbd> — файл сохранится как `image.png` (с автоматической нумерацией: `image 2.png`, `image 3.png` и т.д.).
* **Текст и код:** Скопировали фрагмент кода или заметку? Нажмите <kbd>⌘V</kbd> — создастся текстовый файл `Clipboard.txt`.
* **JSON:** Скопировали валидный JSON? Нажмите <kbd>⌘V</kbd> — сохранится файл `Clipboard.json`.
* **Веб-ссылки:** Скопировали URL-адрес? Нажмите <kbd>⌘V</kbd> — создастся файл ярлыка `.webloc`.
* **Умное определение папки:** Файл автоматически сохраняется в ту папку, которая в данный момент открыта в Finder (Загрузки, Документы, внешний SSD/флешка или Рабочий стол) и сразу подсвечивается.
* **Без конфликтов:** Если в буфере находятся скопированные файлы или папки, утилита пропускает операцию, позволяя Finder выполнить стандартную системную вставку.

### 🖱️ Контекстное меню по правому клику (ПКМ)
Кликните правой кнопкой мыши в любом месте Finder или на Рабочем столе:

1. **Новый файл:** Создание готовых чистых документов в один клик:
   * **Текстовые:** Обычный текст (`.txt`), Markdown (`.md`), JSON (`.json`)
   * **Microsoft Office:** Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`)
   * **Apple iWork:** Pages (`.pages`), Numbers (`.numbers`), Keynote (`.key`)
2. **Скопировать путь:** Копирует чистый POSIX-путь к файлу или папке без лишних окружающих кавычек.
3. **Открыть терминал:** Запускает Терминал прямо в текущей директории.

## 🔒 Настройка разрешений macOS

Для работы утилите требуются стандартные разрешения macOS:

1. **Универсальный доступ (для клавиш Enter, F2 и ⌘V):**
   * Перейдите в **Системные настройки** → **Конфиденциальность и безопасность** → **Универсальный доступ**.
   * Включите тумблер напротив **FinderToys** (или `MacNewFile`).
2. **Расширение Finder (для контекстного меню):**
   * Перейдите в **Системные настройки** → **Основные** → **Объекты входа и расширения** → **Расширения Finder**.
   * Включите расширение **FinderToys**.

## 🛠️ Сборка из исходников

Требуется: macOS 13.0+ и инструменты разработчика (`xcode-select --install`).

```bash
git clone git@github.com:Danikk13/FinderToys.git
cd FinderToys
./build.sh -d -i
```
* `-d`: Создает установочный DMG-образ в папке `dist/`.
* `-i`: Устанавливает и перезапускает приложение в `/Applications`.
