**FinderToys** — нативный, ультралегкий набор инструментов для macOS, устраняющий главные неудобства стандартного Finder. Он возвращает привычные и продуктивные функции: **открытие файлов по клавише Enter**, **переименование по F2**, **сохранение картинок и текста из буфера обмена прямо в файлы по Cmd+V**, контекстное меню **«Новый файл» по правому клику (ПКМ)**, встроенное **сжатие видео и создание GIF**, **конвертацию документов Word в PDF**, а также **объединение PDF**.

В отличие от тяжелых программ на Electron, FinderToys написан на чистом Objective-C и AppKit: **0% нагрузки на процессор** и менее **15 МБ оперативной памяти**.

## ✨ Подробный разбор возможностей

### 1. ⌨️ Удобное управление с клавиатуры: Enter для открытия, F2 для переименования
При переходе с Windows на Mac нажатие <kbd>Enter</kbd> в Finder вместо запуска файла начинает его переименовывать. FinderToys возвращает нормальное поведение:
* **Нажатие <kbd>Enter</kbd>:** Открывает выбранный файл в программе по умолчанию или заходит в выбранную папку.
* **Нажатие <kbd>F2</kbd>, <kbd>⌥ Option + F2</kbd> или <kbd>⌘ Cmd + R</kbd>:** Запускает плавное системное переименование файла.
* **Дополнительные клавиши:** Также работают сочетания <kbd>⇧ Shift + Enter</kbd> и <kbd>⌥ Option + Enter</kbd>.
* **Защита при вводе текста:** Когда вы уже переименовываете файл, ищете в строке поиска Finder или переходите к папке по пути, клавиши <kbd>Enter</kbd> и <kbd>⌘V</kbd> работают как обычно для набора текста.

### 2. 📋 Умная вставка из буфера обмена в файлы (<kbd>⌘ Cmd + V</kbd>)
Больше не нужно запускать графические или текстовые редакторы, чтобы просто сохранить скопированное. Нажмите <kbd>⌘V</kbd> в окне Finder или на Рабочем столе:
* **Картинки и скриншоты:** Скопировали изображение из браузера или сделали снимок экрана? Нажмите <kbd>⌘V</kbd> — файл сохранится как `image.png`. Файлы не перезаписываются — автоматически добавляется нумерация (`image 2.png`, `image 3.png`...).
* **Код и текст:** Скопировали фрагмент кода или заметку? Нажмите <kbd>⌘V</kbd> — создастся `Clipboard.txt`.
* **JSON:** Скопировали JSON-структуру? Нажмите <kbd>⌘V</kbd> — создастся `Clipboard.json`.
* **Веб-ссылки:** Скопировали URL? Нажмите <kbd>⌘V</kbd> — создастся нативный ярлык сайта `.webloc`.
* **Автоопределение папки:** Файл сохраняется именно в ту директорию, которая сейчас открыта (Загрузки, Документы, внешний SSD/флешка или Рабочий стол) и сразу подсвечивается.
* **Без конфликтов:** Обычное копирование и перенос файлов в Finder сохраняются в оригинальном системном виде.

### 3. 🖱️ Контекстное меню по правому клику (Расширение Finder Sync)
Кликните правой кнопкой мыши в любом месте Finder или на Рабочем столе:
* **Новый файл:** Создание чистых шаблонных документов в один клик:
  * **Текст и код:** Обычный текст (`.txt`), Markdown (`.md`), JSON (`.json`)
  * **Microsoft Office:** Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`)
  * **Apple iWork:** Pages (`.pages`), Numbers (`.numbers`), Keynote (`.key`)
* **Скопировать путь:** Копирует чистый системный путь без лишних кавычек.
* **Открыть терминал:** Мгновенно запускает Терминал прямо в текущей папке.

### 4. 🔄 Умные конвертеры файлов (Динамические подменю)
Действия в контекстном меню появляются только тогда, когда выделены соответствующие файлы, не загромождая интерфейс:

* **🖼️ Работа с изображениями (PNG, JPG, HEIC, WebP, TIFF, BMP):**
  * **в PNG / в JPEG / в HEIC:** Конвертация в один клик (текущий формат исходного файла скрывается автоматически).
  * **в PDF:** Быстро превратить одиночное фото или скан в страницу PDF.
  * **Собрать в один PDF:** Выделите 2 и более картинок, чтобы мгновенно объединить их в единый многостраничный PDF.
* **🎬 Работа с видео (MP4, MOV, MKV, AVI, WebM и др.):**
  * **Сжать (H.264):** Высокоэффективное сжатие видео через ffmpeg (CRF 22, пресет fast, tune film, faststart) или системный движок AVAssetExport. Исходный файл всегда сохраняется.
  * **в MP4 / в MOV:** Быстрая смена формата с умной фильтрацией.
  * **в GIF:** Качественное двухпроходное создание GIF с палитрой (12 fps, масштабирование до 720p, алгоритм дизеринга Bayer).
* **📄 Документы Word (.docx, .doc, .rtf, .odt):**
  * **Конвертировать ▸ в PDF:** Нативная многостраничная векторная печать в стандартный формат А4 с выделяемым текстом и полями через AppKit TextKit и PDFKit (установка Microsoft Office или LibreOffice не требуется).
  * **Конвертировать ▸ в TXT:** Мгновенное извлечение чистого текста.
  * **Конвертировать ▸ в DOCX:** Обновление старых файлов `.doc`, `.rtf` или `.odt` в современный формат `.docx`.
* **📑 Работа с PDF:**
  * **Объединить PDF в один:** Выделите несколько PDF-файлов, чтобы мгновенно склеить их в один итоговый документ.

### 5. 🌐 Меню в статус-баре и настройки
* Лаконичная иконка в строке меню с логичной группировкой переключателей:
  * **Горячие клавиши:** Включение/отключение открытия по Enter и вставки ⌘V.
  * **Конвертеры Finder:** Раздельное включение конвертеров изображений, видео или документов и PDF.
  * **Опции конвертации:** Перемещение оригиналов в Корзину после смены формата (не затрагивает сжатие, GIF, PDF или Word).
  * **Статус прав в реальном времени:** Индикатор `✅ Доступ к специальным возможностям: разрешён` или кнопка для выдачи разрешения в один клик.
* **Автоматический язык:** Если система macOS на русском языке — интерфейс полностью на русском. На остальных системах автоматически включается английский.

## 🔒 Разрешения и настройка в macOS

Для работы горячих клавиш в Finder и показа контекстного меню приложению требуются стандартные системные разрешения:

1. **Универсальный доступ (Accessibility) — для клавиш Enter, F2 и ⌘V:**
   * Откройте **Системные настройки** → **Конфиденциальность и безопасность** → **Универсальный доступ**.
   * Включите тумблер напротив **FinderToys**.
2. **Расширение Finder — для меню по правому клику:**
   * Откройте **Системные настройки** → **Основные** → **Объекты входа и расширения** → **Расширения Finder**.
   * Включите тумблер напротив **FinderToys Extension**.

## ❓ Часто задаваемые вопросы (FAQ)

### Как сделать так, чтобы Enter на Mac открывал файлы как в Windows?
Установите FinderToys. Приложение автоматически переназначает <kbd>Enter</kbd> на открытие файлов и папок в Finder, а переименование переносит на <kbd>F2</kbd>, <kbd>Option + F2</kbd> и <kbd>⌘R</kbd>.

### Как вставить скопированную картинку прямо в папку как файл PNG?
Скопируйте любую картинку в буфер обмена из браузера или сделайте скриншот, перейдите в Finder и нажмите <kbd>⌘V</kbd>. FinderToys сразу создаст файл `image.png` в текущей папке.

### Как перевести документ Word в PDF без Microsoft Office?
Выделите один или несколько файлов `.docx`, `.doc`, `.rtf` или `.odt` в Finder, нажмите правую кнопку мыши и выберите **Конвертировать ▸ в PDF**. FinderToys нативно сгенерирует многостраничный PDF А4 прямо в той же папке.

### Разряжает ли FinderToys аккумулятор или замедляет систему?
Нет. FinderToys написан на нативном Objective-C с фильтрацией системных событий. В режиме ожидания приложение потребляет 0% процессора и менее 15 МБ оперативной памяти.

## 🛠️ Сборка из исходного кода

Требования: macOS 13.0+ и Apple Command Line Tools (`xcode-select --install`).

```bash
git clone git@github.com:atlant63/FinderToys.git
cd FinderToys
./build.sh -d -i
```
* `-d`: Компилирует проект и собирает установщик `dist/FinderToys.dmg`.
* `-i`: Устанавливает и регистрирует приложение в `/Applications/FinderToys.app`.
